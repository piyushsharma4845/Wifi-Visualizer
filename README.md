# 📡 Wifi-visualizer
A professional Signal Intelligence dashboard that uses Trilateration and Physics-based Path Loss models to locate Wi-Fi sources.

## 🚀 Live Demo
[Click here to view the Interactive UI & Simulation](https://wifi-visualizer-04.streamlit.app)

> **Note:** Due to browser security restrictions, the automated SSID scanning feature works when run **locally**. The web link serves as a high-fidelity simulation of the tracking engine.

## ✨ Features
- **Automatic Hardware Detection:** Interacts with Windows, Mac, and Linux Wi-Fi cards.
- **Signal-to-Distance Engine:** Converts dBm/Percentage to meters.
- **Weighted Trilateration:** Pinpoints source location using 3-point calibration.
- **Cyber-Security UI:** Neon-themed radar propagation map.
